# YoCut悠剪

轻量浏览器音频编辑器，适合舞蹈训练歌曲的剪切、移动、延长和节奏调整。

- 上传音频，按 4/4 拍网格编辑片段。
- 自动估算 BPM、识别底鼓并辅助对拍。
- 三条音轨，支持跨轨拖动、静音与独奏。
- 可按每拍选区，导出 MP3 或 WAV。
- 提供 110 Hz、Q≈1.3 的 bell 形 EQ 增益。
- “提取纯伴奏/找客服”入口展示微信客服二维码。
- Solo 为互斥模式，最新点击的轨道独奏。
- 链接转音频界面已提供；GitHub Pages 不运行转码服务，线上启用需另接动态后端。

编辑与合成在浏览器中完成。网页刷新后，未导出的编辑内容不会保留。

MP3 编码使用 [lamejs](https://github.com/zhuker/lamejs) 1.2.1。授权说明和 LGPL 文本位于 `vendor/`。
